# ADR-002

## Title

Application State

## Status

Accepted

## Decision

VEAG Foundry will maintain a single global application state (`appState`) that acts as the application's source of truth.

## Rationale

Application data is loaded once and stored centrally.

Views render from application state rather than loading their own data.

Navigation can re-render views without re-fetching data.

Keeps data flow simple and predictable.
